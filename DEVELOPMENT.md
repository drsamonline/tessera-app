# Status: under development

**Not finished, not released.** Published so the work can be inspected, not adopted.

| | |
|---|---|
| Version numbers | Build numbers, not stability promises. `v1.30.0` means the thirtieth build |
| Releases | Every one is flagged **pre-release** on GitHub |
| Data | May be lost. There is no migration guarantee between builds |
| Support | None |

## The gate: this project is finished when

- [ ] The APK has launched on a device and been used for one real task
- [ ] The console has been driven against an engine with a **live connector** behind it, not recorded transports
- [ ] The seven-item mobile bottom bar is resolved (Report merged or moved)
- [ ] The pencil-edit affordance is visible on touch, not hover-only
- [ ] `REVIEW.md`'s four accepted findings are either fixed or formally accepted in writing
- [ ] The licensing questions in `COMMERCIAL.md` are answered, because a commercial licence is on offer

Two of those need a device and a CRM token. The rest are work I can do.

## When it changes

This file is deleted, the pre-release flags come off, the banner comes off the README, and the version goes to 1.0.0 —
in one commit, when every box is ticked.
